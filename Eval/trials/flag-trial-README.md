# KITT flag trial

The original prompts and previous responses are byte copies of the third trial. The current responses replay those 21 conversations, followed by seven new conversations. Each conversation started with a fresh log. The model stayed off.

The scenarios file uses the KITT evaluation format. It includes all exact user turns. The expected messages and flag assertions were encoded after reading the output for regression use. The seven new conversations were worded before reading the revised trigger rules. Once used to change the implementation, treat them as development tests.
